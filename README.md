# Farm-Game-VR

A VR farming game developed in **Unity for the Meta Quest**. The project features a **diegetic tractor control system**, allowing players to operate a tractor using in-game controls.

Players can **purchase, plant, harvest, and sell crops**, creating a farming gameplay loop. The game also features an **inventory system for each hand**, allowing players to store and manage objects while interacting with the environment.

This project was an opportunity to explore **VR development**, interactive controls, inventory management, and farming mechanics in Unity.
